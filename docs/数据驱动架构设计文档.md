# 数据驱动架构设计文档 🎯

## 核心设计理念：零硬编码 Zero Hard-Coded Data

**原则：组件只负责渲染和交互，所有数据都从外部传入**

---

## 📋 数据结构定义（Schema Only）

### 1. 流程配置 Schema
```typescript
/**
 * 流程配置数据结构（仅定义结构，不包含具体数据）
 */
export interface FlowConfigSchema {
  id: string;                          // 流程唯一标识
  name: string;                        // 流程名称
  version: string;                     // 版本号
  description?: string;                // 流程描述
  nodes: NodeSchema[];                 // 节点列表（从外部传入）
  edges: EdgeSchema[];                 // 连线列表（从外部传入）
  settings?: FlowSettingsSchema;       // 流程设置（从外部传入）
  metadata?: Record<string, any>;      // 元数据（完全自定义）
}

/**
 * 节点配置 Schema
 */
export interface NodeSchema {
  id: string;
  type: string;                        // 节点类型（用户自定义）
  title: string;
  description?: string;
  position?: { x: number; y: number };
  config: NodeConfigSchema;            // 节点配置（从外部传入）
  style?: Record<string, any>;         // 样式（完全自定义）
  children?: string[];                 // 子节点 ID
  metadata?: Record<string, any>;      // 扩展字段（完全自定义）
}

/**
 * 节点配置 Schema（完全动态）
 */
export interface NodeConfigSchema {
  // 表单定义（从外部传入）
  formSchema?: FormFieldSchema[];

  // 表单值（从外部传入）
  formValues?: Record<string, any>;

  // 其他配置（完全开放，用户自定义）
  [key: string]: any;
}

/**
 * 表单字段 Schema
 */
export interface FormFieldSchema {
  name: string;                        // 字段名
  label: string;                       // 标签
  type: string;                        // 字段类型（用户可扩展）
  component?: string;                  // 自定义组件名
  defaultValue?: any;
  required?: boolean;
  placeholder?: string;
  disabled?: boolean | string;         // 支持表达式
  visible?: boolean | string;          // 支持表达式
  options?: OptionSchema[];            // 选项（从外部传入）
  validation?: ValidationSchema[];     // 验证规则（从外部传入）
  props?: Record<string, any>;         // 额外属性（完全自定义）
  dependencies?: string[];             // 依赖字段
  children?: FormFieldSchema[];        // 嵌套字段
  metadata?: Record<string, any>;      // 扩展字段
}

/**
 * 选项 Schema
 */
export interface OptionSchema {
  label: string;
  value: any;
  disabled?: boolean;
  metadata?: Record<string, any>;      // 扩展字段
}

/**
 * 验证规则 Schema
 */
export interface ValidationSchema {
  type: string;                        // 验证类型（用户可扩展）
  message: string;
  value?: any;
  validator?: string;                  // 自定义验证器名称
  metadata?: Record<string, any>;
}
```

## 🔧 组件 API 设计（完全数据驱动）

### React 组件
```tsx
import { FlowDesigner } from '@yourname/flow-react';

export interface FlowDesignerProps {
  // ============ 数据相关（必须从外部传入） ============

  /**
   * 流程配置数据（从外部传入）
   * 来源：JSON文件、API、数据库、配置中心等
   */
  config: FlowConfigSchema;

  /**
   * 配置变化回调（保存到外部）
   * 用户决定如何保存：API、本地存储、数据库等
   */
  onChange?: (config: FlowConfigSchema) => void;

  // ============ 数据加载器（可选） ============

  /**
   * 数据加载器（用于动态加载外部数据）
   */
  loaders?: {
    /**
     * 加载节点类型定义
     * @example
     * async () => {
     *   const res = await fetch('/api/node-types');
     *   return res.json();
     * }
     */
    nodeTypes?: () => Promise<NodeTypeSchema[]>;

    /**
     * 加载表单组件定义
     * @example
     * async () => {
     *   const res = await fetch('/api/form-components');
     *   return res.json();
     * }
     */
    formComponents?: () => Promise<FormComponentSchema[]>;

    /**
     * 加载选项数据（用于下拉框、单选、多选等）
     * @param field - 字段配置
     * @example
     * async (field) => {
     *   if (field.name === 'approvers') {
     *     const res = await fetch('/api/users');
     *     return res.json();
     *   }
     * }
     */
    options?: (field: FormFieldSchema) => Promise<OptionSchema[]>;

    /**
     * 加载初始值
     * @param nodeId - 节点 ID
     * @example
     * async (nodeId) => {
     *   const res = await fetch(`/api/nodes/${nodeId}/config`);
     *   return res.json();
     * }
     */
    initialValues?: (nodeId: string) => Promise<Record<string, any>>;
  };

  // ============ 组件注册（可选） ============

  /**
   * 自定义节点组件
   * @example
   * {
   *   'customNode': CustomNodeComponent
   * }
   */
  nodeComponents?: Record<string, React.ComponentType<any>>;

  /**
   * 自定义表单组件
   * @example
   * {
   *   'userSelect': UserSelectComponent
   * }
   */
  formComponents?: Record<string, React.ComponentType<any>>;

  /**
   * 自定义验证器
   * @example
   * {
   *   'uniqueEmail': async (value) => {
   *     const res = await fetch(`/api/check-email?email=${value}`);
   *     return res.json().exists === false;
   *   }
   * }
   */
  validators?: Record<string, (value: any, context?: any) => boolean | Promise<boolean>>;

  // ============ 事件回调 ============

  onNodeClick?: (node: NodeSchema) => void;
  onNodeDoubleClick?: (node: NodeSchema) => void;
  onNodeAdd?: (parentId: string, type: string) => void;
  onNodeDelete?: (nodeId: string) => void;
  onEdgeAdd?: (source: string, target: string) => void;
  onEdgeDelete?: (edgeId: string) => void;

  /**
   * 配置保存前的钩子（可用于数据转换、验证）
   */
  beforeSave?: (config: FlowConfigSchema) => FlowConfigSchema | Promise<FlowConfigSchema>;

  /**
   * 配置保存后的钩子
   */
  afterSave?: (config: FlowConfigSchema) => void | Promise<void>;
}
```

## 📖 使用方式示例

### 方式 1：从 JSON 文件加载（静态配置）

```tsx
// React 示例

import { FlowDesigner } from '@yourname/flow-react';
import { useState, useEffect } from 'react';

function App() {
  const [config, setConfig] = useState(null);
  const [loading, setLoading] = useState(true);

  // 从 JSON 文件加载配置
  useEffect(() => {
    fetch('/configs/leave-approval.json')
      .then(res => res.json())
      .then(data => {
        setConfig(data);
        setLoading(false);
      });
  }, []);

  // 保存配置到服务器
  const handleSave = async (newConfig) => {
    // 用户决定如何保存
    await fetch('/api/flows', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(newConfig)
    });
    setConfig(newConfig);
  };

  if (loading) return <div>加载中...</div>;

  return (
    <FlowDesigner
      config={config}
      onChange={handleSave}
    />
  );
}
```

### 方式 2：从 API 动态加载

```tsx
import { FlowDesigner } from '@yourname/flow-react';
import { useState, useEffect } from 'react';

function App() {
  const [config, setConfig] = useState(null);

  // 从 API 加载配置
  useEffect(() => {
    loadFlowConfig();
  }, []);

  const loadFlowConfig = async () => {
    const response = await fetch('/api/flows/leave-approval');
    const data = await response.json();
    setConfig(data);
  };

  // 保存到 API
  const handleSave = async (newConfig) => {
    await fetch('/api/flows/leave-approval', {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(newConfig)
    });
    setConfig(newConfig);
  };

  return (
    <FlowDesigner
      config={config}
      onChange={handleSave}
      // 动态加载选项数据
      loaders={{
        // 加载审批人列表（从 API）
        options: async (field) => {
          if (field.name === 'approvers') {
            const res = await fetch('/api/users');
            const users = await res.json();
            return users.map(u => ({ label: u.name, value: u.id }));
          }
          if (field.name === 'roles') {
            const res = await fetch('/api/roles');
            const roles = await res.json();
            return roles.map(r => ({ label: r.name, value: r.id }));
          }
          // 其他字段返回配置中的选项
          return field.options || [];
        }
      }}
    />
  );
}
```

### 方式 3：从远程配置中心加载

```tsx
import { FlowDesigner } from '@yourname/flow-react';
import { useState, useEffect } from 'react';
import { ConfigClient } from '@your-company/config-client';

function App() {
  const [config, setConfig] = useState(null);
  const configClient = new ConfigClient();

  // 从配置中心加载
  useEffect(() => {
    configClient.get('flow.leave-approval')
      .then(data => setConfig(data));

    // 监听配置变化（热更新）
    configClient.watch('flow.leave-approval', (newConfig) => {
      setConfig(newConfig);
    });
  }, []);

  // 保存到配置中心
  const handleSave = async (newConfig) => {
    await configClient.set('flow.leave-approval', newConfig);
    setConfig(newConfig);
  };

  return (
    <FlowDesigner
      config={config}
      onChange={handleSave}
    />
  );
}
```

### 方式 5：完全动态加载（所有数据都从外部）

```tsx
import { FlowDesigner } from '@yourname/flow-react';
import { useState, useEffect } from 'react';

function App() {
  const [config, setConfig] = useState(null);

  useEffect(() => {
    loadAllData();
  }, []);

  const loadAllData = async () => {
    // 并行加载所有数据
    const [flowConfig, nodeTypes, formComponents] = await Promise.all([
      fetch('/api/flows/leave-approval').then(r => r.json()),
      fetch('/api/node-types').then(r => r.json()),
      fetch('/api/form-components').then(r => r.json())
    ]);

    setConfig(flowConfig);
  };

  return (
    <FlowDesigner
      config={config}
      onChange={setConfig}
      // 所有数据都动态加载
      loaders={{
        // 动态加载节点类型定义
        nodeTypes: async () => {
          const res = await fetch('/api/node-types');
          return res.json();
        },

        // 动态加载表单组件定义
        formComponents: async () => {
          const res = await fetch('/api/form-components');
          return res.json();
        },

        // 动态加载选项
        options: async (field) => {
          const res = await fetch(`/api/options/${field.name}`);
          return res.json();
        },

        // 动态加载初始值
        initialValues: async (nodeId) => {
          const res = await fetch(`/api/nodes/${nodeId}/config`);
          return res.json();
        }
      }}
    />
  );
}
```

## 🔌 数据源适配器（可选功能）

### 设计思想
提供适配器模式，让用户可以轻松对接不同的数据源。

```typescript
/**
 * 数据源适配器接口
 */
export interface DataSourceAdapter {
  /**
   * 加载流程配置
   */
  loadFlow(flowId: string): Promise<FlowConfigSchema>;

  /**
   * 保存流程配置
   */
  saveFlow(flowId: string, config: FlowConfigSchema): Promise<void>;

  /**
   * 加载节点配置
   */
  loadNodeConfig(nodeId: string): Promise<NodeConfigSchema>;

  /**
   * 加载选项数据
   */
  loadOptions(fieldName: string, context?: any): Promise<OptionSchema[]>;

  /**
   * 加载验证规则
   */
  loadValidations(fieldName: string): Promise<ValidationSchema[]>;
}

/**
 * REST API 适配器（示例）
 */
export class RestApiAdapter implements DataSourceAdapter {
  constructor(private baseUrl: string) {}

  async loadFlow(flowId: string) {
    const res = await fetch(`${this.baseUrl}/flows/${flowId}`);
    return res.json();
  }

  async saveFlow(flowId: string, config: FlowConfigSchema) {
    await fetch(`${this.baseUrl}/flows/${flowId}`, {
      method: 'PUT',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(config)
    });
  }

  async loadNodeConfig(nodeId: string) {
    const res = await fetch(`${this.baseUrl}/nodes/${nodeId}/config`);
    return res.json();
  }

  async loadOptions(fieldName: string, context?: any) {
    const params = new URLSearchParams(context);
    const res = await fetch(`${this.baseUrl}/options/${fieldName}?${params}`);
    return res.json();
  }

  async loadValidations(fieldName: string) {
    const res = await fetch(`${this.baseUrl}/validations/${fieldName}`);
    return res.json();
  }
}

/**
 * GraphQL 适配器（示例）
 */
export class GraphQLAdapter implements DataSourceAdapter {
  constructor(private endpoint: string) {}

  async loadFlow(flowId: string) {
    const query = `
      query GetFlow($id: ID!) {
        flow(id: $id) {
          id
          name
          version
          nodes { ... }
          edges { ... }
        }
      }
    `;
    const res = await fetch(this.endpoint, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ query, variables: { id: flowId } })
    });
    const { data } = await res.json();
    return data.flow;
  }

  // ... 其他方法实现
}

/**
 * 使用适配器
 */
function App() {
  // 用户选择数据源
  const dataSource = new RestApiAdapter('https://api.example.com');
  // 或者
  // const dataSource = new GraphQLAdapter('https://api.example.com/graphql');

  const [config, setConfig] = useState(null);

  useEffect(() => {
    dataSource.loadFlow('leave-approval').then(setConfig);
  }, []);

  const handleSave = async (newConfig) => {
    await dataSource.saveFlow('leave-approval', newConfig);
    setConfig(newConfig);
  };

  return (
    <FlowDesigner
      config={config}
      onChange={handleSave}
      loaders={{
        options: (field) => dataSource.loadOptions(field.name)
      }}
    />
  );
}
```

## ✅ 数据外部化检查清单

### 组件内部（不应该有）
- ❌ 硬编码的节点数据
- ❌ 硬编码的选项列表（如用户列表、角色列表）
- ❌ 硬编码的验证规则
- ❌ 硬编码的初始值
- ❌ 硬编码的业务逻辑

### 组件外部（应该在）
- ✅ 所有节点配置
- ✅ 所有选项数据（从 API/JSON/数据库加载）
- ✅ 所有验证规则（从配置加载）
- ✅ 所有初始值（从 API/数据库加载）
- ✅ 所有业务逻辑（通过回调传入）

```typescript
// 配置存储在数据库，通过 API 读写

function App() {
  const [config, setConfig] = useState(null);

  useEffect(() => {
    // 从后端加载
    fetch('/api/flows/leave-approval')
      .then(r => r.json())
      .then(setConfig);
  }, []);

  const handleSave = async (newConfig) => {
    // 保存到后端
    await fetch('/api/flows/leave-approval', {
      method: 'PUT',
      body: JSON.stringify(newConfig)
    });
    setConfig(newConfig);
  };

  return <FlowDesigner config={config} onChange={handleSave} />;
}
```

### 方案 3：配置中心管理（大型项目）

```typescript
// 配置存储在配置中心（如 Apollo Config、Nacos）

import { ConfigClient } from '@your-company/config-client';

function App() {
  const [config, setConfig] = useState(null);
  const configClient = new ConfigClient();

  useEffect(() => {
    // 从配置中心加载
    configClient.get('flow.leave-approval').then(setConfig);

    // 监听配置变化（热更新）
    configClient.watch('flow.leave-approval', setConfig);
  }, []);

  const handleSave = async (newConfig) => {
    // 保存到配置中心
    await configClient.set('flow.leave-approval', newConfig);
    setConfig(newConfig);
  };

  return <FlowDesigner config={config} onChange={handleSave} />;
}
```

## 📝 总结

### 核心原则

1. **零硬编码** 🚫
   - 组件内部不包含任何业务数据
   - 所有数据都从外部传入

2. **数据外部化** 📦
   - 支持多种数据来源：JSON、API、数据库、配置中心
   - 用户完全控制数据的加载和保存

3. **完全可配置** ⚙️
   - 所有功能都通过配置控制
   - 用户可以扩展任何部分

4. **框架无关** 🔄
   - 核心逻辑不依赖任何框架
   - React/Vue 只是适配层

5. **用户自由** 🎨
   - 用户决定数据从哪里来
   - 用户决定数据存到哪里去
   - 用户决定如何扩展

---

**这样设计，用户可以：**
- ✅ 使用任何数据源
- ✅ 使用任何存储方式
- ✅ 完全控制数据流
- ✅ 自由扩展功能
- ✅ 零业务耦合

**组件只负责：**
- ✅ 接收数据
- ✅ 渲染 UI
- ✅ 处理交互
- ✅ 触发回调

**完美的职责分离！** 🎯
